# 财神输入法 v2.0.2

本版包含输入性能优化、学习数据一致性修复和安装改进，适用于 Windows 10/11 x64，
同时提供 64 位和 WOW64 32 位应用所需的输入法组件。

## 下载

- **Setup 安装版**：适合普通安装和从 2.0.1 升级，提供安装向导、开始菜单入口及标准卸载。
- **Portable 便携版**：完整解压后，以管理员身份运行包内安装脚本，并长期保留解压目录。
- 两个包均包含自带 .NET 8 运行时的设置中心，并附带各自的 `.sha256` 校验文件。
- 页面中的 Source code ZIP 和 TAR.GZ 对应 `v2.0.2` 标签源码。

## 性能改进

- 打字统计改为后台合并保存，减少每次上屏时的磁盘等待。
- 混拼搜索减少临时对象和路径复制，并使用整体查询工作预算约束搜索量。
- 首屏按需获取候选，翻页和展开时继续加载，保持置顶、英文和自定义短语的排序规则。
- 同一轮按键处理复用配置快照，减少重复文件检查。
- 剪贴板采集、图片编码、散列和入库移到专用后台线程，降低设置界面的阻塞。

## 问题修复

- 修复清空学习词后旧词重新出现，以及撤销学习后旧记录仍被保存的问题。
- 修复多个应用分别学习搭配时互相覆盖，保存失败后保留增量并重试。
- 修复同音候选重排后学习次数、时间被写成另一个候选的元数据。
- 修复搭配模型容量限制失效，限制长期使用中的内存增长。
- 词库加载超过首次等待时间后自动恢复候选；空格、数字和鼠标选择会补查刚就绪的候选。
- 收紧个人词库、统计、置顶及剪贴板数据的权限。
- 修复安装及便携配置脚本在 Windows PowerShell 5.1 下的 UTF-8 编码误读。

## 升级与隐私说明

Setup 升级会保留现有设置和个人数据。输入法 DLL 会驻留在已打开的应用中，升级后
关闭相关应用并重新打开，或保存工作后注销并重新登录，才能让所有宿主加载新版本。

沙箱宿主使用公共系统词库与资源，不直接访问个人学习词、自定义短语、置顶和统计；
普通桌面应用保留这些个性化功能。运行时保持全离线，密码及私密输入范围继续完全旁路。

本版尚未进行 Authenticode 代码签名。Windows 可能显示“未知发布者”或 SmartScreen
提示。下载后请核对随附的 SHA-256；校验值用于确认文件完整性，不能替代发布者签名。
