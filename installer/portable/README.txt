财神输入法便携版使用说明

系统要求
- Windows 10 或 Windows 11，x64 架构。
- 本发行包未做 Authenticode 代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。

安装
1. 将 ZIP 完整解压到一个长期保留、路径稳定的目录，不要直接在压缩包内运行。
2. 右键“安装(以管理员身份运行).bat”，选择“以管理员身份运行”。
3. 安装成功后使用 Win + Space 切换到“财神输入法”。

卸载
1. 保留原解压目录，右键“卸载(以管理员身份运行).bat”并以管理员身份运行。
2. 卸载脚本注销当前目录内的 TSF 组件，并移除本版本创建的快捷方式和启动项。

完整安装体验、升级回滚和“已安装的应用”卸载入口，请改用同版本 Setup.exe。
校验下载完整性时，请使用 GitHub Release 同时提供的 .sha256 文件。
